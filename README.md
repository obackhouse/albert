# albert

Toolbox for manipulating, optimising, and generating code for Einstein summations.

This project combines a Python package with a C++ extension built by CMake and
scikit-build-core.

## Development

Install the package and development tools with:

```sh
python -m pip install -e '.[dev]'
```

Run the test suite with `pytest`, format Python code with `ruff format`, and
check Python lint rules with `ruff check`.
